# Gastos Anuais

App web (PWA) de controle de gastos. Instalável no Android e no iPhone.

Publicado em: https://SEU-USUARIO.github.io/gastos-anuais/

## Instalar no celular
- **Android (Chrome):** menu ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartilhar → *Adicionar à Tela de Início*.

## Atenção
Nunca suba planilhas, extratos ou chaves secretas para este repositório (o `.gitignore` já bloqueia `.xlsx`, `.pdf`, `.csv`, `.ofx`, `.env`).
