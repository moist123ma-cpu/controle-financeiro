# Gastos Anuais v15

Controle de despesas, receitas e metas.

- Abra `index.html` no navegador para usar a ferramenta.
- Em **Importar**, use **Baixar backup** para salvar sua base e **Importar base Excel** para abrir uma base existente.
- Para atualizar uma instalação existente, faça um backup e substitua os arquivos no mesmo endereço de hospedagem. Em outro endereço, importe o backup para recuperar a base local.
- Para instalar como aplicativo, disponibilize a pasta por HTTPS. No Android, use **Instalar app** no menu do Chrome. No iPhone, use **Adicionar à Tela de Início** no Safari.
- A leitura de PDF e Excel pode precisar de internet para carregar as bibliotecas. O login e a sincronização também dependem de internet.

A versão simplificada mantém os sete módulos e concentra o resumo na tela inicial. Vencimentos, filtros, gráficos e outros detalhes podem ser abertos conforme a necessidade.
